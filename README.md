## Manual Installation (Developer Mode)

If you want to run or test the extension locally:

1. Clone or download this repository.
2. Open your browser's extension management page (`about:debugging` in Firefox or `chrome://extensions` in Chromium).
3. Enable **Developer Mode** (if required).
4. Click **Load Temporary Add-on** (Firefox) or **Load Unpacked** (Chromium) and select the project root directory.
